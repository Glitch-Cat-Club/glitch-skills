# Glitch Skills

Free skills from Glitch Cat Club.

| Skill | What it does |
|---|---|
| [glitch-walk](glitch-walk/) | Shows you how one part of your own project works: the real screens, every step in order and the code behind each one. |

## Set one up

Each skill is one folder.
Copy it into your AI tool's skills folder, open your project and ask.
